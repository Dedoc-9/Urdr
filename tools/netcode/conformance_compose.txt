# URDRCMP1 conformance — DO THE PROVEN SLICES COMPOSE. The first Stage 5 laws, stated BETWEEN
# modules rather than inside one.
#
# THE SEGMENTATION LAW. simulate(w, log) cut at ANY tick k and resumed from the snapshot at k
# reproduces the tail exactly, frame digest for frame digest. That is the associativity of
# world-stepping over a linear log, and it is what makes a checkpoint a checkpoint: resuming must be
# observationally identical to never having stopped. No amount of testing persist ALONE would reveal
# a defect here, because the defect would live in the seam.
#
#     MEASURED: 0 divergences over EVERY cut of two independent worlds -- 39 on the collide world
#     (body-body contact, T=40) and 119 on the arena world (T=120).
#
#     AND IT ESTABLISHES SOMETHING THE CODE DECLINED TO CLAIM. worldstep.simulate_trace documents its
#     per-frame snapshots as DISPLAY-ONLY and says nothing there feeds back into the tick -- a
#     caution written when nobody had checked whether it needed to be one. Those snapshots ARE valid
#     resumption points. The caution was stronger than the code required.
#
# TWO PLANTS, ATTACKING FROM DIFFERENT DIRECTIONS, because they fail differently and one alone would
# have left the other mode untested. Perturbing ONE WORD of a snapshot diverges at EXACTLY that cut
# (1 of 39) -- the comparison is sensitive to the state it claims to compare. Carrying state OUTSIDE
# the snapshot diverges at EVERY cut (39 of 39) -- which is the defect the law exists to catch and
# the one a perturbation would never exercise.
#
# does_not_show: that the world state IS (pos, vel) in general -- no hidden state affects THESE runs,
# which is a statement about these fixtures rather than a structural proof; that a checkpoint WRITTEN
# by persist and READ BACK reproduces the tail, which is the replay law across the serialization
# boundary and is the declared successor, NOT claimed here; anything about concurrency, joining or
# leaving, which is Stage 5's remaining work.#
# THE SERIALIZATION REPLAY LAW, AS A COMMUTING DIAGRAM.
#
#     fold_from o deserialize o restore o serialize  ==  fold_from
#
# Continue a trajectory from an interior pose; or serialize that pose, store it, restore it, and
# continue from what came back. Both paths must land on the SAME future tail, bit for bit. MEASURED:
# 14 boundaries across three glide scenes, 0 round-trip failures, 0 tail divergences.
#
#     THE SEAM IS THREE MODULES WIDE AND EACH OWNS ONE EDGE. glide._fold_from proves a trajectory is
#     resumable from an interior pose -- already gated by `splice`, which checks resumption WITHIN
#     glide for every log and interior split. storecost defines the canonical pose encoding. persist
#     proves byte-faithful storage under a digest law. What none of them asserts, and what no test
#     inside any one of them could, is that the COMPOSITION preserves behaviour. A diagram is not
#     owned by any of its edges.
#
# THREE PLANTED AXES, chosen so no two share a failure mode:
#
#     1. corrupted bytes    -> refusal at restore     14 of 14
#     2. permuted schema    -> refusal at serialize   14 of 14
#     3. mismatched tail    -> valid restore, diverges 11 of 11 testable
#
#     AXIS 2 DID NOT DO WHAT THE DESIGN PREDICTED, AND THE REASON MATTERS MORE THAN THE PREDICTION.
#     Swapping ground_height and facing was expected to serialize cleanly and diverge on replay -- a
#     silent semantic fault. It REFUSES instead, at storecost.serialize, because `facing` carries a
#     RANGE guard (0..3) and every ground height in this corpus is >= 24. Stronger than predicted and
#     a WEAKER guarantee than it looks: the schema is protected by a range coincidence, not by
#     structure. A scene whose ground heights fell in 0..3 would serialize the permuted pose without
#     complaint. 0 boundaries here have ground == facing; that is a fact about THIS CORPUS.
#
#     AXIS 3 IS TESTABLE AT 11 OF 14, structurally. At a scene's LAST boundary there is no next
#     command, so there is no wrong continuation to resume against. Reported as 11 of 11 testable
#     rather than 11 of 14 with three silent misses.
#
# does_not_show: that the pose schema is structurally permutation-proof -- see axis 2; that
# `worldstep` states are durable, which they are NOT and by design (D11 durability boundary).
