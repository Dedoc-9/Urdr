# URDRLIV1 conformance — THE KEYED HEARTBEAT AND THE WELL-FOUNDED COUNTDOWN. The residual URDRPAT1
# declared and URDRAGR1 was resting on. NO new glyph (kernel frozen).
#
# WHAT THIS CLOSES. auditgraph priced undetected equivocation at kappa and sold it as converting an
# INVISIBLE INTEGRITY attack into a VISIBLE AVAILABILITY one. patience then showed the ladder
# collapses to 0/0/0 when a server STALLS instead of excluding, because under Chandra-Toueg a silent
# peer and a slow one are the same observation. Both declared the residual; neither closed it. A
# client that cannot tell DENIAL from BAD WEATHER raises no alarm.
#
# THE AUTHENTICATION IS KEYED, AND THAT IS THE POINT. A heartbeat derived from PUBLIC data is not
# evidence of anything — SHA-256(session | tick) is computable by every observer, so an adversary on
# the path emits bytes that match and the client resets its counter forever while the server is gone.
# That is the COUNTERFEIT RESET. Measured over the same 12-tick family: the unkeyed scheme accepts
# the forgery 12 of 12, the keyed scheme 0 of 12. The token is
#
#     HMAC-SHA256(secret, MAGIC | session | tick), compared with hmac.compare_digest
#
# so a reset requires PROOF OF POSSESSION of pre-shared material, verified against the tick the client
# is in — bound to clockauth's server-attested band ((36, 38) at now=40, lat=3, jitter=1), never to
# wall-clock, since no wall-clock enters an authority path in this arc.
#
# REPLAY IS BOUNDED, NOT ELIMINATED, AND THE BOUND IS EXACT. The measured replay window is exactly 1
# tick of 12: a token minted for tick t verifies at t and nowhere else. An intercepted token is
# therefore worth only the tick it was already evidence for, so it cannot mask a stall — which is the
# attack. Calling that "replay prevented" would be the inflation.
#
# THE COUNTDOWN IS PURE SUBTRACTION OVER THE NATURALS. budget - 1, and the fault fires exactly when
# the next value would be 0, so the value never reaches 0 and never goes negative: the descent is a
# well-founded relation on (N, <) rather than a loop with a floor. Decided: from a full budget under
# total silence exactly PATIENCE-1 = 3 ticks survive and the 4th raises, and the minimum budget ever
# returned is 1. The max(0, ...) CLAMP is kept as a live plant because it looks defensive and is not —
# the clamped variant runs 500 ticks of silence without ever firing. That one line is the liveness
# residual reopened.
#
# THE MASKING LADDER, measured with ONE intercepted token replayed through a TOTAL 40-tick stall:
#
#     honest step                4 ticks hidden   (refuses at PATIENCE)
#     bounded sliding window     8 ticks hidden   (doubles the adversary's exposure)
#     accepts-any-history       40 ticks hidden   (the whole stall, forever)
#
# The third is the verifier that ships in the wild: "is this a token we recognise" instead of "is this
# the token now demands". It authenticates possession and forgets freshness entirely.
#
# THE FAULT IS A NORMAL Exception, A DELIBERATE DEPARTURE FROM THE SPEC THIS RUNG WAS WRITTEN TO. The
# request was a BaseException subclass so the fault would propagate through intermediate handlers. The
# INTENT is right and is honoured; the MECHANISM was measured and it damages the gate. verify.py wraps
# every stage in `except Exception` — 457 of them — so a BaseException subclass does not redden a row,
# it ABORTS the process: no row, no remaining stages, no GATE FAILED line, and no byte-identical
# output to diff, which destroys the determinism check that is this repo's spine. Measured
# (Exception recorded, BaseException recorded) = (True, False), pinned as data rather than argued.
# The anti-swallowing property is obtained the way this repo obtains guarantees: _step_swallowing is a
# live plant that catches its own fault and returns a budget, and step_does_not_swallow asserts the
# real step lets it out.
#
# THE DIGESTS BELOW ARE EMITTED, NOT INSCRIBED — AND STILL FROZEN. `liveness.py --emit` prints exactly
# these three lines and `emitted_matches_pinned` proves the file on disk is that output, so no hex is
# hand-typed. They are NOT regenerated by the gate: a golden the gate rewrites at run time cannot
# detect drift, which is precisely L23 (a checker that cannot fail). The module emits; a human pins;
