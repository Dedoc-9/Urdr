# URDRPNG1 conformance — THE PING POLICY: the scheduling / sample-selection layer feeding URDRLES1's ack
# window, organised around ONE invariant. URDRLES1's min-floor is honest "as long as one true-timed ack lands
# in the window" — an assumption it cannot itself guarantee — and its residual was open-ended (a patient
# total delay widens the band without bound). THE INVARIANT, stated as a falsifiable theorem over a client
# strategy space rather than a hope — CONDITIONAL MONOTONE DISADVANTAGE: GIVEN a session floor established
# from a window the client did not pad, every lever the client can pull resolves against the client, i.e. for
# every strategy sigma, reach(sigma) <= reach(honest) + DRIFT_ALLOWANCE, and for every non-total-delay sigma,
# reach(sigma) <= reach(honest), where reach = lat + jitter is exactly how far back URDRCLK1 lets that client
# claim. FOUR LAWS COMPOSE TO IT: (1) AUTHENTICATED ECHO — each ping carries a server-keyed nonce; a forged or
# replayed echo is refused, so coverage cannot be faked; (2) COVERAGE OR REFUSAL — fewer than MIN_SAMPLES
# authenticated echoes freezes the band (no rise, jitter 0) and after STARVE_WINDOWS refuses, so silence never
# pays; (3) THE LOWER-HALF RULE — a delay can only push an RTT up, so only the fast half is trusted and the
# jitter is its spread, leaving partial delay unable to inflate; (4) THE SESSION FLOOR — the latency may never
# exceed all-time-min-RTT//2 + DRIFT_ALLOWANCE, so a client's own honest early samples pin them for the
# session and total delay buys a CONSTANT, not a growing advantage.
#
# THE PRECONDITION IS LOAD-BEARING AND ITS FAILURE IS THE DECLARED RESIDUAL — THE COLD START. A client that
# pads EVERY ack from the moment it connects never founds an honest floor: it records an inflated one and
# keeps a permanently WIDER band than honest play. That client is NOT covered by the theorem, the gap is
# MEASURED (not hypothesised), and it is pinned here as the `coldstart` scene and asserted every sweep. What
# still bounds it: padding beyond MAX_RTT is refused outright, so reach <= cold_start_ceiling() =
# MAX_RTT//2 + DRIFT_ALLOWANCE + MAX_JITTER = 11; and URDRCLK1 clamps the band to the lag window regardless,
# so backdating never exceeds MAX_REWIND however the floor was set. It buys a BOUNDED constant, larger than
# honest play. It is not merely unfixed: a client padding from connect is indistinguishable, FROM TIMING
# ALONE, from a client on a genuinely slow path, so refusing it would refuse the honest laggy player
# identically — closing it needs an out-of-band prior (route/population baseline or a trusted first
# measurement), which is the declared successor. The sweep carries a fixed WITNESS asserting the residual is
# still real, so the boundary cannot silently go vacuous.
