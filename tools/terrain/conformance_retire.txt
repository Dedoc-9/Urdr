# A RETIRED LAW NAMES ITS SUCCESSOR, AND NOTHING OUTSIDE ITS OWN MODULE MAY CALL IT.
#
# THE COMPANION `reachable` COULD NOT ASK THIS. Reachability asks whether a door OPENS;
# this asks whether it is still the door the tree ENDORSES. Both read green while the
# wrong one is in use — which is not hypothetical. `sealframe` retired `named_host_ok`
# for admitting readings, wrote the paragraph, built `conditions_sufficient`, and pinned
# the old law's unsatisfiability with a falsifier. `rollbench` imported the retired law
# anyway and rebuilt the identical defect on top of it; `reachable` certified the pair
# REACHABLE, correctly, because a literal satisfies it.
#
# A COMMENT DOES NOT TRAVEL. A CALLER READS AN API, NOT A PARAGRAPH. So the retirement
# is DATA — RETIRED[symbol] = (successor, reason) — swept tree-wide from the AST.
#
# sweep   — every declared retirement's verdict, whether each carries a reason, and the
#           declared-not-discovered floor (module-level callables defined vs retired).
# plants  — STALE (a replanted cross-module call, the line this rung removed), CLEAN for
#           a module naming the law only in PROSE, UNNAMED for a successor that does not
#           exist, VACUOUS for an empty register, and the OWNER's own calls staying lawful.
#
# does_not_show: WHETHER A LAW OUGHT TO BE RETIRED. Retirement is the OWNER'S declaration,
# read from a register — a law that is dead in a maintainer's head and live in the file is
# invisible to this sweep, which would certify the whole tree CLEAN the day before someone
# writes the first register that catches something. It does not show that the successor is
# CORRECT, only that it exists and is named. It does not sweep `tests/`, by rule: a falsifier
# may call a retired law to pin why it was retired, and reddening on that would delete the
# evidence for the retirement being enforced. `declared != discovered`.
#
# DECLARED: the register's membership, the SWEPT directory list, and the PRE_REPAIR pin.
# All three are choices, pinned as data so the boundary is a floor rather than a survey.
#
# RE-PINNED: THE HISTORICAL REFERENCE WAS `HEAD`, WHICH IS A FACT ABOUT THE CHECKOUT AND NOT ABOUT
# THE DEFECT. The strongest evidence here is that the sweep catches the defect in the SOURCE THAT
# CARRIED IT; v1 fetched that source with `git show HEAD:...` and passed ON THE MACHINE WHERE IT WAS
# WRITTEN, because the rung was not yet committed there. The instant it landed, HEAD became the
# REPAIRED file, the sweep read CLEAN, and the assertion inverted — red on the operator's machine,
# and incapable of going red on the author's. A FALSIFIER ANCHORED TO A MOVING REFERENCE PASSES ONLY
# FROM WHERE IT WAS WRITTEN. The reference is now a FIXED commit sealed by the SHA-256 of its blob,
# so a substituted artifact REFUSES rather than passing, and UNAVAILABLE (no such object here) is
# kept distinct from MISSED (the detector failed) so a shallow clone cannot buy a quiet pass.
#
# The `plants` digest is UNCHANGED by that repair, which is the point: the five plants never read
# git. Only `sweep` moves, because the module gained two callables and the floor counts them.
