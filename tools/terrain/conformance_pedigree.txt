# REGISTRY, an escape hatch for defects that cannot be reconstructed from the artifact, currently
# EMPTY because every defect found so far is derivable.

# hierarchy — derived evidence outranks a good fingerprint; UNIDENTIFIED is not refused; a planted
#             retirement bites; the registry's emptiness is asserted rather than assumed.
