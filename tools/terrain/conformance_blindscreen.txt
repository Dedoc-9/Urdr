# URDRBLS1 conformance — CHEAPNESS IS NOT SOUNDNESS. The whole family of cheap pre-screens refuted at
# once, and the one hole autoroute left open. NO new glyph (kernel frozen).
#
# WHY THIS RUNG EXISTS. autoroute routes a query to the cheapest level that CAN decide it, and drops a
# fetch only where a witness search and a syntactic proof agree. What it could not yet do is tell apart
# two situations that look identical from inside a cascade:
#
#     (a) THIS TIER DECIDES — the cheap answer is backed by a determinacy proof
#     (b) THIS TIER IS ALL I CAN AFFORD — the cheap answer is backed by nothing
#
# A cascade that cannot distinguish those will eventually accept a screen BECAUSE it is cheap. This is
# the missing falsifier, and it covers the FAMILY rather than one predicate at a time.
#
# MEASURED — EVERY CHEAP INVARIANT IS BLIND TO THE VERDICT, AND SO IS THEIR CONJUNCTION. Four candidate
# pre-screens, each refuted by an equal-invariant / opposite-verdict pair over a 545-occupancy corpus
# (170 breached, 375 intact, so the corpus is not one-sided): cell_count (divergence 4),
# boundary_occupancy (2), tile_prefix (16), occupancy_defect (16) — 4 of 4 refuted. And then the result
# that closes the family: ONE PAIR agrees on ALL FOUR SIMULTANEOUSLY and has OPPOSITE verdicts — two
# 16-cell occupancies differing in 2 cells, one BREACHED and one INTACT. Stacking cheap checks does not
# converge on the answer, because they are all blind in the same direction.
#
#     POSITIVE CONTROL, so this is blindness rather than a degenerate corpus: connectivity — the
#     expensive measurand — separates that same pair (True against False). If it could not, the pair
#     would prove nothing about the invariants.
#
# THE OPERATIONAL COST, COUNTED. Install a cell-count screen ahead of the flood fill and point it at a
# population every member of which shares the submitter's cell count: it clears 8 of 8 peers and clears
# 3 of them WRONGLY. The population is asserted to exercise both arms (5 agreeing, 3 disagreeing),
# because a population of honest peers only would have made the screen look free.
#
# THE COST ORDER AND THE DECISIVENESS ORDER ARE DIFFERENT ORDERS. Sorted by cost: cell_count 1,
# tile_prefix 1, occupancy_defect 2, boundary_occupancy 3, connectivity 4. Sorted by what they settle:
# the first four settle NOTHING and only the last settles anything — cheap-that-decide is EMPTY,
# expensive-that-decide is (connectivity), orders_agree FALSE. A cascade is sound only where the two
# orders COINCIDE, and autoroute's CERT tier qualifies not because it is first but because inputset
# proved determinacy there. The router is checked by SIGNATURE to take no blind invariant on any
# decision path — 4 functions scanned (verify_routed, screen_decides, plan_for, peers_agree), 0
# appearances — the same discipline that keeps cohort's centrality graph unwired.
#
# THE HISTORICAL TRAJECTORY THIS FORMALIZES, WITH ITS DATES CORRECTED. A four-step chemical structure
# determination was offered as a blueprint for the cascade: biosynthesis -> extraction -> isomerization
# -> degradation. Checked against the record, three of four attributions do not hold and the ordering is
# not a trajectory:
#
#     1844  Saint-Evre determines the empirical FORMULA of safrole.
#     1869  Grimaux and Ruotte investigate and NAME safrole. Separately Fittig prepares piperonal by
#           permanganate oxidation of piperic acid — 1869 rather than 1871, a different substrate and
#           reagent from the cleavage the blueprint cites, and Remsen is not named in the 1911
#           encyclopaedic account of it.
#     1885  Eijkman shows "shikimol" (from Illicium anisatum) and safrole are the SAME compound, on the
#           grounds that they share an empirical formula and have other similar properties. He isolates
#           shikimic acid from that plant the same year — the one step attributed correctly.
#     1888  Bruhl establishes that safrole's C3H5 group is an ALLYL group.
#
# So the structural feature the blueprint has being isomerized in 1886 was not established until 1888.
# The corrected sequence is FORMULA -> NAME -> IDENTITY-BY-SHARED-INVARIANT -> STRUCTURE, and it tells
# the OPPOSITE story: each step used a weaker invariant than the question demanded and the structural
# answer came LAST — not because cheap-first was sound but because the structural instrument did not
# exist yet. The cascade is that trajectory's INVERSE, and it is sound only because the arc already owns
# the structural answer.
#
# AND THE 1885 STEP IS A NAMED INSTANCE OF THE DEFECT. "Same empirical formula plus similar properties,
# therefore the same compound" is identity from an invariant that provably cannot decide identity —
# safrole and isosafrole share C10H10O2 and are different compounds. The conclusion was right; the
# argument as stated does not reach it. That is cohort's refutation (1) with the chemistry removed, and
# the lattice analogue is pinned here: identical cell count, identical boundary, identical tile prefix,
# OPPOSITE verdict (True, True, True, True).
#
#
# WHY THEY ARE ALL BLIND, WHICH IS BETTER THAN FOUR COINCIDENCES — AND IT COMES FROM VALUATION THEORY.
# Geometric valuation theory studies functionals obeying inclusion-exclusion,
# Phi(K) + Phi(L) = Phi(K u L) + Phi(K n L), and its classification theorems — Hadwiger 1957 for rigid
# motions, Ludwig-Reitzner 1999 and 2010 for the equi-affine and centro-affine cases — are RIGIDITY
# results: add mild regularity plus a symmetry group and an infinite-dimensional space of candidates
# collapses onto a short list. MEASURED HERE: three of the four cheap invariants ARE valuations —
# cell_count, tile_prefix and occupancy_defect each satisfy inclusion-exclusion with 0 violations over
# 400 pairs (boundary_occupancy is set-valued, so not a real-valued candidate at all) — and THE BREACH
# VERDICT IS NOT, violating it 24 times in the same 400. So the blindness is not four unlucky choices:
#
#     A VALUATION ASSIGNS ONE NUMBER TO ONE SET. BREACH ASKS WHETHER TWO DESIGNATED FACES LIE IN THE
#     SAME FREE COMPONENT — a relative, TWO-POINTED property of a set together with a choice of
#     boundary pair. It is not an absolute functional of the set, so inclusion-exclusion has nothing to
#     decompose.
#
# That is a REASON, not a proof, and it is graded as one. Closing the gap would need a Hadwiger-style
# classification of lattice valuations under this arc's symmetry group, then a check of whether any
# member of the resulting short list decides breach. Not done here, and not claimed.
#
# AND THE FIFTH REFUTATION BIT THIS MODULE'S OWN CORPUS, ONE INVARIANT AFTER IT WARNED ABOUT EXACTLY
# THAT. The free-component count is the natural escalation — topological rather than metric, not cheap,
# and not a valuation either (29 violations of 400). Searching the 545-occupancy corpus for an
# equal-component / opposite-verdict pair finds NOTHING (corpus_found_a_witness FALSE). Read as a
# result that would have been "free_components survives", and it would have been wrong: every corpus
# member is wall-like so its free space always touches both faces, and the discriminating case is
# simply absent. A HAND-BUILT pair refutes it at once — everything-but-one-interior-cell (free space
# one component, touching neither face, INTACT) against a two-thick wall with an aligned tunnel (free
# space one component, spanning, BREACHED): components (1, 1), verdicts (INTACT, BREACHED), divergence
# 35. FIVE OF FIVE BLIND. The corpus caveat this file already carried came true inside the file.
#
# THE STATUS IS FALSIFIED, NOT DISPROVEN-IN-GENERAL, AND THE VOCABULARY ENFORCES IT RATHER THAN
# PROMISING IT. Every candidate carries a durable row in falsification_record() — candidate, status,
# witness, failure mode, impact — and the status vocabulary admits FALSIFIED and OPEN and NOTHING
# STRONGER. There is no CONFIRMED, no PROVED and no IMPOSSIBLE anywhere in it (checked: statuses used
# ('FALSIFIED',), forbidden words present (), every row carries a witness True, 6 of 6 falsified WITH a
