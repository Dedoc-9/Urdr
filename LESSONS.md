# LESSONS — the discipline this repo inherits (as text, not as a dependency)

Urðr is a **standalone** project. It imports no code from Dentatus/Chronicle or Ursprung.
What it imports is the discipline those projects paid for. Each lesson below is stated as a
law of *this* repo, with where it is enforced. Lessons are cited as lineage, not authority:
`cited ≠ implemented` — the enforcement column is what counts.

| # | Lesson (paid for upstream) | Law here | Enforced by |
|---|---|---|---|
| L1 | Canonical bytes → SHA-256; identity *is* content. | Every value has one canonical byte form; `digest = sha256(canon(v))`. No digest is ever computed over non-canonical bytes. | `urdr/canon.py`; determinism falsifiers |
| L2 | No-inflation: evidence may never exceed maturity. Compile it to an unrepresentable state, don't police it after the fact. | Over-claiming source is **rejected by the static checker** (`URDR-INFLATE-STATIC`); `MEASURED` is unwritable in source (`URDR-EVIDENCE-UNEARNED`) and constructable only by the verify primitive ᛞ. A dynamic guard (`URDR-INFLATE-DYN`) remains as an unreachable-but-armed latch. | `urdr/check.py`, `urdr/values.py`; non-vacuous rejection tests |
| L3 | Determinism is an environment, not a hope: `PYTHONHASHSEED=0`, UTF-8 forced on Windows (`PYTHONUTF8=1`), no wall-clock, no unseeded RNG, no set/dict-order dependence, no absolute paths in results. | The interpreter core never calls a nondeterminism source; the gate re-runs programs in isolated subprocesses with a pinned env and compares digests bit-for-bit. | `verify.py` |
| L4 | Windows is a first-class host; Unicode dies at the console unless you force UTF-8 at every boundary. | All file I/O is explicit `encoding="utf-8"`; stdout is reconfigured to UTF-8; runner docs give the PowerShell incantation. | every `open()`; `urdr.py`; README |
| L5 | Validity, not outcome: a test that cannot fail proves nothing; a gate must contain a case that is *supposed* to go red. | The suite ships must-reject programs (checker must refuse them) and a deliberately tampered digest fixture the gate must fail. If the tamper case passes, the gate itself is broken and reddens. | `examples/rejected/`, `examples/must_fail/`, `verify.py` |
| L6 | Grade every claim; a green test certifies execution, never that a name means what it says. | Every capability is graded maturity × evidence in the boundaries ledger; README claims link to the ledger; no capability is described above its grade. | `spec/D5-ledger.md` |
| L7 | Capture nondeterminism at the boundary, never fake it away (clocks, RNG, floats, external reads are *inputs*). | The core stays pure and effect-free. Effects arrived (R4) exactly as promised: typed capabilities — reads recorded at the boundary as inputs inside content identity, writes planned in-language and executed at the līmes. | `urdr/capability.py`; `tests/test_capability.py`; D1 §16 |
| L8 | Bounded execution: an interpreter without a fuel meter is a nondeterministic halt oracle in disguise. | Evaluation carries a deterministic fuel budget; exhaustion is a *deterministic* error (`URDR-FUEL`), identical on every host. | `urdr/evaluate.py` |
| L9 | Build for extraction: every component must stand alone. | Lexer, parser, checker, evaluator, store, canon are separate stdlib-only modules with no circular imports; each is unit-tested in isolation. | `urdr/` layout; `tests/` |
| L10 | Arrival-order-independent canonical ordering is how you tame concurrency without lying about it. | Ported later as the deterministic-actor rung (canonical `(tick, actor, seq)` delivery order). Not implemented yet; graded `SPECULATIVE / N/A`. | ledger (R2 rung) |
| L11 | Integrity is not truth: reproducibility proves a record is unforged and re-derivable, never that the decision it records was wise. | Stated in README and ledger; the language's own vocabulary (`Grounded`, `MEASURED`) is defined as *verifier-passed*, not *true*. | README §honest boundaries; D1 §semantics |
| L12 | The membrane: if a read perturbs authoritative state, the change crossed the membrane and is wrong by definition. | ☽ (view) is a pure function of the store; the store is immutable; ☿ (edit) returns a *new* store with a new digest. There is no API through which a view can mutate. | `urdr/values.py` (immutable store); lens-law falsifiers |
| L13 | A bridge-mounted view of the working tree lies after out-of-band changes (paid for 2026-07-16, twice in one day): (a) files rewritten from outside serve NEW bytes truncated at the STALE cached length — `verify.py` arrived syntactically valid and exited 0 silently; (b) after a host-side `git gc`/repack, the mounted view's ref+object resolution split-brains (`show-ref` reads the ref, `rev-parse` can't find the object) — one commit attempt from that state would have orphaned history. | Sessions working through a mounted view verify byte-lengths after every out-of-band write (a rename round-trip busts the stale cache), and treat git as **read-only from the mount** after any host-side `gc` — commits and pushes happen on the host. | `tests/test_gate_guard.py` (ROWS_FLOOR + the truncation falsifier redden the gate on mode (a)); session playbook for mode (b) — procedural, not mechanical, and stated as such |
| L14 | A self-amplifying scheme's stability bound must be AUDITED over the full trajectory, never estimated from initial conditions (paid for 2026-07-17, the Marangoni sea S2): the naive CFL estimate `|κ·Δc| ≤ 1` from the initial gradients said κ=1/4 was safe; but Marangoni sharpening grows its OWN gradients, and κ=1/4 went negative mid-run. κ=1/16 was earned by a tick-by-tick monotonicity audit across the whole evolution, and the gate re-runs that audit every time. The estimate misleads exactly when the dynamics are interesting; the trajectory is the law. | `tools/terrain/sea.py` (the pinned κ); `sea-marangoni` (mass + monotone-30/30 + peak) and `sea-marangoni-selftest` (the over-bound κ overshoots negative yet conserves — the bound is load-bearing) |
| L15 | A falsifier is only evidence once its planted defect BITES — and the plant can be silently masked three ways (paid for 2026-07-18, three times in one arc): by DEFENSE-IN-DEPTH (a second mechanism catches the scenario, so gutting the first never reddens — the persist membership falsifier passed with both layers off because a swap leaves a *missing* file a third check catches; the honest falsifier was overwrite-not-swap), by an INSENSITIVE CORPUS (a ±1 step-gate drift survived every chunkload vector until a rise == max_step case existed), and by a HABITUAL ANCHOR (a sprint-gait mutation on latarith's all-walk corpus mutates nothing — the anchor must be chosen by READING the corpus, not by precedent). | Before any golden pins: plant the defect, watch the falsifier redden; where defense-in-depth exists, prove each layer individually redundant (one off → still green) AND jointly load-bearing (all off → red); pick corpora boundary-tight and anchors corpus-aware. | The per-rung red-first record in the D5 volumes and commit messages (`ff5cf15..cb14318`); the `*-placement-selftest` rows (in-gate source mutation that must diverge); `latarith_rs`'s in-binary corpus-count check |
| L16 | A number carried in prose is a mercenary: it deserts on contact with the source (paid for 2026-07-18/19: a "32-config / 345-config" soundness corpus quoted from prose was actually 24 when read from `verify.py`; live counts written in idiom VARIANTS — "25 Rust + 14 C99", "**25** single-file Rust" — slipped a manual sweep three commits running until doc-currency named them). | Every count is read from its artifact at claim time (`testsRun`, the row total, the filesystem, the corpus literal); live counts appear in tracked docs only in the digit idioms the checker scans; historical counts are pinned to a commit (the D5 Volume-II epoch-stamp convention), never left floating. | `doc-currency` + its non-vacuity selftest; the D5 volume convention; `latarith_rs` (`checks != 24` → `selfcheck FAILED`) |
| L17 | Resumable-in-memory ≠ recoverable-through-death, and the environment lies about process lifetime (paid for 2026-07-18/19, two modes): (a) a recovery claim needs a REAL process boundary — a successor whose only channel to its predecessor is the store — and the boundary finds laws memory hides (the k = 0 seed-facing mismatch was invisible to every in-memory test, because nothing in-process ever resumes at boundary 0; the falsifier caught it only because the resume law was tested from the restored record); (b) a "background" process in the bridge VM dies with its call (die-with-parent, per-call PID namespace), while a `pgrep -f` liveness poll MATCHED ITS OWN COMMAND LINE and reported the corpse RUNNING for fifteen minutes. | (a) The death boundary is modeled, never simulated: a fresh subprocess, run twice, byte-identical, knowing only the store + the static authority + the continuation request; (b) long work runs where execution persists (the workspace), results bridge back under L13's byte-verification, and a liveness probe must be structurally unable to match itself. | (a) `resurrect-death` (gate row, real successor ×2) + `tests/test_resurrect.py`; (b) session playbook — procedural, stated as such (the L13 mode-(b) genre) |
| L18 | **Polarity inversion on a hierarchy** — reading a comparison in the wrong direction against a tree, three separate times in one session. The 2-adic valuation (`ctz`) was adopted as octree LCA depth when hierarchy lives in the HIGH bits and the correct operation is `clz`; a handed-down predicate read `clz(x⊕y) < k` as "collision-relevant proximity" when that condition means FAR APART; and `lca_depth ≥ threshold` was proposed as disjointness when a deep common ancestor means the SAME subtree. All three are sound-looking and all three invert. | Any predicate over a hierarchy states, in its own docstring, which END of the word carries the structure, and ships the inverted form as a live plant with its measured failure rate. | `voxlat` (`_lca_by_ctz`, 3231/7140 = 45% correct, and INVERTED on leaf siblings — reports root divergence for a one-bit difference); `disjoint` (`_disjoint_by_lca_ge`, admits 402 NON-COMMUTING pairs as safe) |
| L19 | **Vacuity — the characteristic failure of this architecture** — five occurrences in one session, and it is *not* wrongness. An empty answer is indistinguishable from a correct one. A single-valued edit family makes every pair commute, so its census confirms ANY predicate including the inverted one it exists to refute; a 60-edit slice makes every greedy batch a SINGLETON, so an unsound grouping rule scores clean; a level comparison run on a corpus where every level scores zero distinguishes no levels and was one keystroke from "soundness never breaks at any level," proved on nothing; a proposed `max{k : P ⊆ γₖ(αₖ(P))}` bound passes at maximum burn because **a void is sound**; and a vacuity TRIPWIRE was itself insufficiently vacuous and stayed silent. | **Every census carries a non-vacuity precondition and RAISES rather than returning a quiet zero.** A comparison across configurations must first assert the configurations differ; a batching census must assert grouping happens; a scanner must be shown to fire on a planted defect. Silence must be loud. | `ashdepth` (`VacuityError`/`ASHDEPTH-VACUOUS`, `vacuity_witnesses()` pinning all four as constants, `EMPTY_CORPUS` tripwire); `frontier` (`greedy_census_is_not_vacuous`, `the_small_slice_was_vacuous`); `syntaxclean-selftest` |
| L20 | **A sample promoted to a universal** — the inflation this repo forbids, arriving four times by different routes: a single benchmark's 7.82 cm splat error quoted as *the* geometric error of a technique whose real spread is three orders of magnitude by capture condition; a cubic overflow exponent read off RANDOM SAMPLING whose own samples also supported quadratic between some bounds; a 66.7× collapse ratio carried over from an exploratory run at a superseded family size; a 27% fast-path yield quoted as an accelerator's value when it is an artifact of one corpus's density. | Worst-case-over-inputs is the measurand, decided by enumeration where the space allows it. A figure from a superseded run is recorded as stale rather than silently swapped. A quantity that varies with corpus is reported as a CURVE, never a point. | `voxlat` (4·B³ decided exhaustively, not sampled); `frontier` (`yield_curve`, `the_pinned_fraction_is_an_artifact`); `recirc` (the stale 6/66.7× pair recorded in-place); `horn` (`worst_relative_cost_bruteforce` as an independent oracle) |
| L21 | **Wrong units** — a defect measured in a space that cannot express it. Luminance delta proposed for information asymmetry (a uniform tint shifts 36 of 36 pixels for defect 0; culling one occluder shifts one cell for defect 3); a float z-score proposed for a fraud verdict, which is not reproducible across platforms; a flip *rate* proposed for quantization defect, which hides WHICH cells and the adversary picks cells. | A defect is measured in the codomain's own units, and for this arc that is **integers over sets**. Defects then compose by ordinary addition (`\|A △ C\| ≤ \|A △ B\| + \|B △ C\|`, decided over 32768 triples, 0 violations) and no float enters an authority path. | `tierview` (`\|Vis_high △ Vis_low\|` in cells, `luminance_delta_is_the_wrong_quantity`); `geoquorum` (integer cohort disagreement, not a z-score) |
| L22 | **Elegance that costs detection** — the most dangerous class, because the proposal looks *more* principled than what it replaces. A provenance certificate hashing only its own metadata is cleaner than one bound to geometry, and lets an attacker lift a permissive certificate onto a restricted capture. Fixed-point equality is a prettier integrity check than raw-lattice equality, and it COLLAPSES 400 distinct captures onto 5 fixed points — conflating an honest capture with a doctored one that dropped an obligation, which is precisely the omission attack the arc exists to catch. | Any simplification of an authority check is measured against the attack it is supposed to stop, before it is adopted. A check that admits more pairs as identical has raised false negatives, however elegant its derivation. | `provbind` (`_digest_metadata_only`, lift attack measured succeeding then failing); `recirc` (`_fixedpoint_as_integrity`, `doctored_collides_with_honest`) |

| L23 | **A checker that cannot fail is not evidence** — the sharpest failure this session produced, and it shipped THREE TIMES before an audit caught it. `auditgraph` sold "price == kappa, 771 of 771, 0 exceptions" on the grounds that *two computations agreeing is a measurement; one computation is a definition restated*. The two functions were the SAME loop over the SAME subsets calling the SAME `components`, separated only by a guard that provably cannot change the answer. It was refuted BY MUTATION rather than by argument: corrupt the shared primitive and the census still reports 0 exceptions, quietly shrinking its own denominator from 771 to 495. The numbers were right the whole time; the reason to believe them was not. | Any claim of the form "two methods agree" names the primitive each method uses and asserts they share none. Every cross-check ships a MUTATION PROBE that corrupts the shared dependency and demands the check go red — L15 (the plant bites first) applied to a CHECKER rather than to a claim. A check whose failure mode has never been observed is a hypothesis. | `auditgraph` (`menger_census` via max-flow vs subset enumeration; `cross_check_is_falsifiable` returning (circular 0, menger 181/10, family 24); `circular_check_cannot_fail` keeping the inert check as a named object rather than a comment) |
| L24 | **Hardening the numerator leaves the denominator** — the immediate sequel to L23, and it was found by a one-line question from outside. After the Menger cross-check de-circularized *what was measured*, the family it was measured OVER — `connected_graphs`, hence every census total — was still built entirely from the same flood fill. Under the identical planted fault the family at order 5 silently shrank from 728 to 476 and RAISED NOTHING, so a fault that narrowed the world without causing disagreements would still have passed. Separately, the same primitive silently DROPPED out-of-range and negative vertices, returning a plausible `False` to a caller who had asked about a different graph. | A cross-check covers the population as well as the statistic: the predicate that CONSTRUCTS the family is cross-checked by an independent route and carries its own mutation probe. Input that cannot be interpreted is a typed refusal, never a confident answer to a different question. | `auditgraph` (`is_connected_by_flow`, `family_census` 1099/0/1099/772, `family_check_is_falsifiable`, `validate_graph` raising `AUDITGRAPH-REFUSE` on out-of-range / negative / self-loop / malformed edges) |
| L25 | **A product written down instead of a counter read**, and **a code chosen without checking the namespace** — two cheap errors with the same root: asserting a quantity that was available to be measured. `bombtest`'s header claimed 24576 explored transitions, which is states × rules; the measured count of LEGAL transitions is 13824, because boundary-blocked moves never fire. And `auditgraph` was given MAGIC `URDRAUD1`, already held by `audible` — a digest is `H(MAGIC \| name \| payload)`, so a shared prefix defeats exactly the domain separation the prefix exists to provide. Neither was caught by 1725 falsifiers; the first was caught by reading the counter, the second by COMBING THE DOCS. | A count that an instrument can produce is read from the instrument, never derived from a formula in prose (L16, extended from doc counts to in-code claims). An identifier drawn from a namespace is checked against that namespace mechanically, and the check is a gate row rather than a habit. | `bombtest` (`never_claim_census` returning the read count; the gate asserting legal < states × rules); `magicuniq` + `magicuniq-selftest` (injectivity over all 90 MAGIC-bearing modules, with a planted duplicate proving the row can redden) |
| L26 | **A tuned constant is a theorem nobody looked for** — and the check on that suspicion is to ask what OBJECT the number is a property of. `THICK = 2` sat in the capture layer looking like a fitted parameter, carried a declared-regime caveat, and inherited a Guggenheim note admitting the 1/2 agreement bar was a fitted law with no derivation. It was neither: measured over spanning walls, min-cut(wall) is 1 at thickness 1 and 2 at thickness 2, so the constant was Menger's minimum vertex cut all along, computable from the wall's own geometry. Replacing the threshold with the theorem cost nothing and bought three things a threshold cannot have — a SCREENING LAW instead of a tolerance (below k the verdict provably cannot move, 32 tried, 0 flips), an IMPOSSIBILITY CHECK instead of a bar (a peer differing by fewer than k cells and reporting a different verdict is not an outlier to forgive, it is provably faulty), and the DISCHARGE of the declared regime rather than its inheritance. Four measurands were proposed across the arc and THREE died on contact with a witness: Jaccard overlap is blind to structure, longest-run is INVERTED relative to the truth (it over-flags the safe case, wrong in the dangerous direction), and the boundary reduction does not exist at all. | Before declaring a constant as policy, ask what mathematical object it is a property of and whether that object can be measured. A tolerance is a confession that the mechanism is unknown; where the mechanism is known, the same number arrives as a theorem and brings an impossibility proof with it. Every rejected measurand is PINNED as a live witness rather than deleted, so the reason a superseded predicate was wrong stays falsifiable and cannot quietly return. And a constant that genuinely stays declared says so with its falsifier attached: the criticality charge peak here is not adopted AND not refuted, because a charge curve was never measured, and claiming the measurement ruled it out would be the inflation this repo forbids. | `cohort` (`min_cut` / `gap_table` (3,1,1)(4,1,1)(4,2,2)(5,1,1)(5,2,2); `screening_law_census` (2,32,0); `sub_gap_disagreement_is_impossible` (2,32,0) with `at_or_above_the_gap_disagreement_becomes_possible` (2,496,16) proving the bound tight; `jaccard_is_blind_to_structure`, `run_length_is_inverted`, `boundary_does_not_determine_breach`, `hex_duality_fails_in_3d` as four pinned refutations; `the_peak_is_not_adopted` (12,12,False)) |

Roadblocks met upstream that this design routes around **by construction** rather than by
assuming they have vanished:

1. **Float drift across hosts/accelerators** — v0.x core is integer-only with defined wrap;
   floats, if they ever arrive, arrive as a differential-checked accelerator path, never as
   the source of truth (directive §5c; the trilemma is surrendered honestly: leak-explicit,
   not leak-free).
2. **Hash/dict iteration order** — canonical serialization sorts keys; digests never touch
   Python iteration order; `PYTHONHASHSEED=0` is set anyway (belt and braces).
3. **Actor message-order nondeterminism** — not inherited; deferred to R2 with the canonical
   logical order already proven upstream. Until then, no concurrency syntax exists at all.
4. **Windows console encoding** — UTF-8 forced programmatically; ASCII digraphs make every
   program typeable and diffable even where glyphs cannot render (`typeable ≠ renderable`).
5. **A green gate hiding a vacuous suite** — the gate red-tests itself (L5).
